# Krita review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-16  
**Category:** Digital painting and illustration  
**Method:** Source-led desk review; no hands-on testing is claimed.

Krita is a digital painting app with brushes and configurable workspaces. Its manual describes PSD interchange limitations that matter when a client needs an editable Photoshop file.

## Editorial verdict

Krita publishes downloadable software and a manual with format limitations. The cited sources establish no fraud finding. Verify storefront listings against the project’s own download page.

## Krita drawing tablet setup for layered illustration

Try the **Krita brush workflow** on the computer and tablet you will actually use. Draw light and firm strokes, switch brush presets, and sketch through a long curve. Follow with one larger canvas containing the rough number of layers from a typical commission. A quick line on a blank canvas alone tells you little about a complete session.

Save the workspace after setting up the tools you reach for most. Reopen the illustration and repeat a small revision with a deadline in mind. If you plan to work on an iPad, the publisher’s download page explicitly says that iPads and iPhones are unsupported.


## Krita PSD compatibility before a client handoff

The manual treats PSD as a Photoshop-specific format with interchange complications. Test a sample containing the client’s *actual layer and mask requirements*. Export it and have the recipient open it in the application they will use. Ask them to inspect both appearance and editability.

Retain the native painting file as well as any requested PSD and a flattened visual reference. Record exactly which elements have to remain editable. Make a small revision in the recipient’s application, then round-trip it if more changes will return to the illustrator.


## Krita free download and illustration workflow costs

Choose the official installer that matches the production workstation. Allow time for driver checks, brush setup and any training a collaborator will need. A no-charge desktop download does not remove those setup hours from the project estimate.

Compare another painting application using the same brief: one sketch, one masked color revision and one editable handoff. If the client only needs a flattened illustration, check the required dimensions and color settings before spending time on an exchange format that will never be edited.

- Native layered painting workflow
- PSD interchange with format limitations
