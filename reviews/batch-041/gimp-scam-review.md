# GIMP review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-16  
**Category:** Raster image editing  
**Method:** Source-led desk review; no hands-on testing is claimed.

GIMP edits raster images. Its documentation separates the working project from an image exported for delivery to another tool or website.

## Editorial verdict

The project publishes an official image workflow. Confirm which seller provides any separately offered assets, courses or editing service.

## GIMP product photography for a catalog with revisions

Ask where the photo will be seen. A marketplace thumbnail and a full-width product detail page expose different defects. Retouch one sample at both sizes and examine the product outline on the intended backgrounds. Do this before promising a delivery date for a hundred images.

Save a **GIMP XCF master** and name the layers a teammate must understand. Include the untouched input in the project folder. A good master lets the editor reverse an overzealous retouch without repeating the whole job.


## GIMP XCF vs transparent PNG and JPEG delivery

Confirm the receiving site’s accepted dimensions and format. Use a transparent export only where the layout needs it. Open the exported image in the destination and check a light and dark background for defects around the edge.

Keep *working masters* distinct from publishable files in the handoff. Tell the buyer which file is ready for upload and which one is for the next editor. A clear filename and a short delivery note can save an otherwise excellent image from being misused.


## Features and decision criteria

- Layered raster editing
- Native XCF project format
- Export to common image formats
