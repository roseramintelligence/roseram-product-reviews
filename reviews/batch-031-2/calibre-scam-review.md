calibre is a free, open-source ebook manager with library, conversion and ebook editing tools. Conversion quality depends on the structure of the original file.

## Editorial verdict

The project documents its free software and conversion pipeline. The sources establish no fraud finding. Check whether a separately sold service adds work you actually need.

## calibre EPUB conversion for a book with footnotes

Start with a rights-cleared chapter containing a heading, a footnote and an illustration. After **calibre EPUB conversion**, jump through the table of contents, follow the note and return to the right paragraph. Then increase the font size and see whether the caption still sits beside the correct illustration.

The conversion manual describes multiple stages and configurable processing. Inspect a difficult chapter before turning on broad cleanup rules. If the converter merges paragraphs or mistakes running headers for titles, revise the source or use the editing tools, then repeat the test on a second sample.


## calibre ebook metadata for a library with multiple editions

Import two editions with similar names and verify that the author, cover, series order and identifier belong to the correct file. Choose a policy for translated titles and revised editions before applying bulk edits. Keep reference copies of the files you imported so you can reconcile a mistaken merge.

When moving to another computer, rehearse restoring the *library with its metadata*. Check the expected number of entries, open files from more than one format, and confirm that a custom tag or series field survives the move.


## calibre ebook delivery on your reading device

Send one test book using the exact reader and transfer method you intend to support. Compare navigation and line breaks at a small screen size. A book that looks fine in a desktop preview may still have a hard-to-read table on the device.

For a commercial ebook, preserve the accepted output and run the checks required by the destination store. Decide who handles layout corrections and metadata changes after delivery. For a personal library, weigh those checks against whether the file opens and remains easy to search and read.
