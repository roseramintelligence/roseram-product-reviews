# Teamwork Desk review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-16  
**Category:** Client helpdesk and customer-support software  
**Method:** Source-led desk review; no hands-on testing is claimed.

Teamwork Desk is a helpdesk product designed to sit alongside Teamwork project delivery. Plans vary by agent, ticket workflow, reporting, integrations, customer portal and AI support features.

## Editorial verdict

Teamwork Desk is most relevant when a services team wants customer support and project execution to share context. Compare the agent-based total, AI add-ons, ticket volume, API limit and the work required to keep the helpdesk connected to delivery.

## Teamwork Desk review: support beside client delivery

Teamwork Desk is presented as a helpdesk for service businesses, with a connection to Teamwork's project-management product. A support request can therefore sit near the client work it creates, which may help agencies and consultancies understand how service effort affects delivery. The ticketing product includes shared inbox functions, customer-facing help options and team workflows.

That relationship is useful only if support and delivery teams agree on what should become a project task and who owns the handoff. Test a common request from first email to resolved ticket, then follow any resulting work into the project system. Check how duplicated emails, reopened tickets and requests from several people at one client are grouped. A shared platform should make ownership clearer, not merely move the same conversation into another queue.


## Teamwork Desk pricing and agent counts

The current Desk pricing page lists Starter at $9.50 per agent per month billed yearly, Pro at $17 and Premium at $33, with Enterprise quoted. Starter is described for up to ten agents; Pro adds unlimited agents, ticket time tracking, triggers and live chat; Premium adds capabilities such as reporting, custom fields and service-level agreements. These are displayed plan terms, not a guarantee that every feature is available in every region or legacy account.

Calculate cost using agents who need to respond, not just the total headcount. Check whether occasional agents, contractors or supervisors need a paid seat, and include the annual commitment. The page lists Dotty as an add-on at $69 a month with a stated volume of ticket analysis and drafted replies. Treat that as a separate usage-based line item and confirm fair-use or additional-volume charges before enabling it.


## Teamwork Desk ticket routing, portals and reporting

The public comparison describes ticket merging and splitting, private notes, forms, customer portals, help documentation and agent productivity reporting, with feature availability differing by plan. A customer portal can reduce repetitive status requests, while a clear ticket taxonomy helps route service issues to the right person. Reporting depends on teams using statuses and categories consistently.

Create a small pilot with the most common inbound request types. Measure first response and resolution using definitions everyone understands, and check what happens when a ticket is reopened or transferred. Publish only help articles that have a named owner and review date. Before promising a service-level target, confirm how business hours, pauses and priority rules work in the actual account.


## Teamwork Desk AI, API limits and integration checks

Teamwork describes Dotty as a support add-on that summarizes tickets, surfaces similar cases and drafts replies for an agent to review. The published description keeps a human in control of sending the response. Teamwork support documentation also lists a rate limit of 120 API requests per minute for Desk and notes that rate-limit headers are returned. An integration that ignores these limits can fail during a busy support period.

Use a test inbox to assess whether summaries preserve important constraints and whether suggested replies need factual correction. Do not auto-send generated text without an approval policy. For API or third-party connections, monitor remaining quota, apply bounded retries and confirm the connector uses an authorized consent flow. Audit which ticket content is shared with an AI feature and how long it is retained.


## Teamwork Desk alternatives and the SCAM Review question

Compare Teamwork Desk with Help Scout, Freshdesk, Zendesk and a shared mailbox using the same ticket volume, agent count, client portal, reporting and project handoff needs. Include the separate cost of the Teamwork project product if your workflow depends on both, along with AI add-ons and annual pricing. A support platform that does not match the team's client workflow may add another system without improving resolution.

Teamwork's official pricing and help pages describe Desk features, add-ons and API limits; they do not establish that Teamwork Desk is a scam. This is a source-based desk review, not a live ticket trial or support-quality measurement. Confirm current seat rules, AI volumes, data export and service-level definitions before routing client requests through it.


## Features and decision criteria

- Shared inbox and ticket workflows for client support
- Customer portal and help documentation options
- Teamwork project integration, API and optional AI support tools

## Pricing considerations

Dotty AI is listed as a separate add-on at $69 per month for analysis of 1,000 tickets and 100 drafted replies. Pricing, fair-use terms and included capabilities should be checked on the current Desk pricing page.
