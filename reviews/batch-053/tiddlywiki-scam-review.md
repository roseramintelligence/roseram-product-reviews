# TiddlyWiki review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-24  
**Category:** Personal knowledge wikis  
**Method:** Source-led desk review; no hands-on testing is claimed.

TiddlyWiki is an open-source, non-linear personal web notebook built around small information units called tiddlers. Its official site describes linking, tagging, lists and macros, and the project presents browser and server options. Saving, hosting and backup choices depend on the chosen setup.

## Editorial verdict

TiddlyWiki suits people who want a highly adaptable personal wiki and are comfortable learning its structure and storage approach. It can be used without complex server infrastructure in some forms, but a dependable save and backup routine remains essential.

## Start with one small connected notebook

Create a few notes that refer to one another, then try tags, lists and a longer narrative assembled from smaller pieces. This reveals whether the tiddler model matches the way the user organizes ideas. It also makes the learning curve visible before important information depends on the setup.

The official site describes information in semantically meaningful chunks linked and composed into larger views. That flexibility can reward experimentation, while making conventions and naming choices more consequential.


## Choose the storage and saving model deliberately

The project has browser and server-oriented options, and their save behavior is not interchangeable. Identify where edits are stored, how they are written back and what happens if a browser closes unexpectedly. A workflow that feels local still needs a clear persistence plan.

Test create, edit, close and reopen on a disposable notebook. Then restore a copy from backup. This review did not install TiddlyWiki or verify a particular saving plugin or hosting provider.


## Treat extensibility as an ongoing choice

Macros and additional components can shape the wiki around a specialized task. Add one extension at a time and document why it is needed. Each customization can affect portability, upgrades and the experience of a future maintainer.

If another person must access the notebook, explain its basic navigation and conventions. A highly personal information system is useful only when its owner can still locate and interpret the material later.


## Evaluate open formats and migration needs

Before importing a large archive, test a representative note with links, attachments and formatting. Compare the source and resulting tiddlers. Keep an untouched backup until the migrated structure has been inspected and the extraction route is understood.

The official project describes itself as open source and emphasizes user control. That is useful context, but not proof that every configuration is easy to move. This review does not audit security, compatibility or a specific plugin collection.


## Features and decision criteria

- Non-linear personal web notebook
- Small reusable information units
- Links, tags, lists and macros
- Browser and server deployment options

## Pricing considerations

The project describes itself as open source. Hosting, extensions, storage and maintenance can involve separate choices or costs; no universal service plan or hands-on setup is evaluated here.

## Frequently asked questions

### Is every TiddlyWiki installation a single local HTML file?

No. The official project also describes Node.js and server options; confirm which edition and saving method you plan to use.

### Does open source automatically provide backups?

No. Create and test a backup routine for the specific deployment.

### Is it a conventional folder of Markdown notes?

Its core model uses tiddlers and WikiText; evaluate import and export needs before migrating.
