# Thunderbird review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-16  
**Category:** Desktop email and account management  
**Method:** Source-led desk review; no hands-on testing is claimed.

Thunderbird is a desktop mail client. Its support documentation distinguishes the profile that holds user data from the application installation.

## Editorial verdict

The project documents where profiles live. Confirm that any outside migration service identifies what data it will handle and what remains on the server.

## Thunderbird profile backup for a retiring computer

Ask the mailbox owner for the oldest message they may still need. Find it and determine whether it lives on the server or in a local folder. Make a **Thunderbird profile backup** using the documented process before removing the original installation.

Restore a copy to another test profile and inspect a message with an attachment, local folders and account settings. A new installation that can receive mail has cleared only the first hurdle. The owner should also be able to find an old commitment.


## Thunderbird local folders migration and account setup

List the accounts and how people sign in to each. Test incoming mail and a single outgoing message to an address you control. Confirm the display name, sending identity and signature before bringing over custom rules.

Schedule the *mail cutover* around the team’s workday and keep the old profile available until validated. A small checklist saves a manager from guessing whether an empty folder belongs to synchronization, account selection or a genuine missing archive.


## Features and decision criteria

- Multiple email account workflows
- Local Thunderbird profile data
- Backup and migration procedures
