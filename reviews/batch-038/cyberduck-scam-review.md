# Cyberduck review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-24  
**Category:** Server and cloud storage browsers  
**Method:** Source-led desk review; no hands-on testing is claimed.

Cyberduck is a server and cloud storage browser for Mac and Windows. Its official site lists protocols and services including SFTP, WebDAV and object-storage providers. It links the related Mountain Duck product separately, so browsing remote storage should not be confused with mounting it as a local disk.

## Editorial verdict

Cyberduck is relevant when a person needs an understandable desktop interface for remote files across supported storage systems. Test the actual account and a reversible transfer. The client interface, the storage account and the permissions applied on the server remain separate parts of the workflow.

## A successful connection is only the first boundary

Seeing a remote folder confirms that part of the connection works. It does not establish whether the account can perform the actions the job requires or whether a file has arrived intact. Begin with a small reversible task using disposable material.

Upload a file, retrieve it and inspect the retrieved result. Keep the destination explicit so a test does not accidentally change a production asset. This review did not connect to a server or verify a particular cloud account.


## The storage account still defines access

A friendly client cannot make an overly broad account appropriately scoped. Decide which folders and actions the user needs before configuring a connection. Keep the distinction between a saved connection and the authority attached to its credentials understandable.

Try the workflow with the intended limited account rather than an administrator account that hides permission problems. Check both the ordinary transfer and an operation that should be denied. These are application acceptance questions, not a claim of a completed security audit.


## Browsing and mounting solve different tasks

Cyberduck’s homepage distinguishes its storage browser from the separately linked mounting product. A person occasionally transferring assets may need a different interaction from someone expecting files to behave like a local drive all day. Describe the task before choosing between those approaches.

Include the way files are opened, changed and verified in that comparison. A familiar-looking folder does not settle whether a remote edit completed or what happens during a connection interruption. The actual storage and integration need to support the intended routine.


## Remote storage has costs beyond the desktop tool

A cloud account may charge for capacity, requests or data movement under its own terms. Keep those costs separate from the client’s download or license decision. Estimate the normal workflow and the occasional larger transfer rather than assuming the tool name defines the entire budget.

Compare alternatives with the same storage provider and representative task. Roseram did not benchmark transfer speed, audit credential storage or certify compatibility with every listed backend. This review is a source-based analysis of the storage-browser role.

## Frequently asked questions

### Does Cyberduck provide the cloud storage itself?

It is a client for accessing supported storage systems. The account, capacity and permissions on those systems are separate.

### Is Cyberduck the same product as Mountain Duck?

No. The official site links Mountain Duck separately for mounting remote storage as a local disk.

### What should a first connection test include?

Use an expendable folder to upload, download and verify a file, then confirm the account’s intended access boundaries.
