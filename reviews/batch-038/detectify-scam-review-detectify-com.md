# Detectify review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-24  
**Category:** Application security and attack-surface monitoring  
**Method:** Source-led desk review; no hands-on testing is claimed.

Detectify combines external attack-surface discovery with application and API security testing. Its public pricing page lists Starter from €0 annually, Standard from €2,500 annually, Professional from €5,000 and Enterprise from €15,000, with additional charges for assets and certain scanning products.

## Editorial verdict

Detectify may suit an organization that wants continuous discovery and security testing across internet-facing assets, web applications or APIs. The entry plan price does not mean all scanning is included: the pricing page lists separate asset- or target-based charges for several product areas. Scope the domains, API targets and internal environments before comparing the annual platform fee, and retain manual penetration testing where the risk requires it.

## Identify which security surface you need to monitor

Detectify describes a platform that combines external attack-surface management, web application scanning, API scanning and internal scanning. Those are distinct products with different setup and coverage. Begin with an asset inventory and a clear authorization boundary so the service only scans systems you own or are allowed to test.

A team focused on unknown public subdomains may prioritize surface discovery; a product team may need authenticated application tests or REST and GraphQL API checks. Do not assume every listed product is included in every subscription. Ask for the exact components and targets in the proposal.


## Read the platform fee alongside asset charges

Detectify’s public pricing page lists annual platform fees starting at €0 for Starter, €2,500 for Standard, €5,000 for Professional and €15,000 for Enterprise. The same page says added assets, domains, environments and IP ranges can cost extra, and some application, API and compliance scans have separate fees.

Count every domain, subdomain, IP range, API target and internal environment you want covered. Request an itemized quote showing the annual platform fee, each product charge, included target counts, overage rates, onboarding and renewal. A free Starter platform fee should not be read as unlimited free security scans.


## Understand what a scanner can and cannot replace

Automated security tests can help find issues between periodic reviews. Detectify’s own buying guide says the platform complements penetration testing, not replaces it. A scanner can miss context-specific authorization problems, business logic issues and weaknesses that need a human to reproduce.

Use results to prioritize investigation and remediation. Confirm important findings manually, retest after fixes and document areas outside the scan scope. Never present an automated “no findings” state as proof that an application is secure.


## Validate authorization and scan safety

Before pointing a scanner at a production system, verify ownership and scope, then coordinate with the service owner. Understand whether tests can create records, submit forms or trigger rate limits. Use a staging environment where possible and schedule production testing with monitoring and incident contacts available.

Review the onboarding requirements for domain verification, authentication and internal agents. Test a limited target and confirm that evidence is useful to engineers. These are recommended controls and not a report that Roseram ran Detectify scans.


## Compare the operational fit and contract

The public plan comparison varies user and team allowances, integrations, SSO, internal scanning and support. A security team should consider alert ownership, ticketing, data retention and how scan results connect to the fix workflow. Measure the time spent triaging rather than equating more alerts with better security.

Check contract renewal, trial length, cancellation, service-level language, subprocessor terms and export options. Ask how assets are counted when DNS changes and how the quote responds to acquisitions or new product environments. This review uses Detectify’s published product and pricing material; it does not make a claim about effectiveness for a particular site.


## Features and decision criteria

- External attack-surface discovery and monitoring
- Web application and REST/GraphQL API scanning
- Plan limits differ by users, teams and support
- Some security products and assets carry extra charges

## Pricing considerations

Detectify states that additional costs can apply for assets, domains, environments and IP ranges; Application, API and PCI scanning can also be separately charged. The platform fee is not a complete cost estimate. Confirm tax, currency, trial period, asset count and included products in an itemized quote.
