Check that the expected content, file naming and relevant metadata are understandable. A completed progress indicator is not the same as a usable media asset.

Include one unsupported or unavailable input in the evaluation discussion. Ask how the application explains the problem and whether a failed operation affects any current usage allowance. This review does not report a download benchmark or certify output quality. Compare the actual file and the documentation instead of assuming that a format name establishes fidelity.

If the purpose is an editing project, inspect the result in that project rather than relying on playback alone.
