## Compression balances file size with accepted appearance

The catalog advertises compression and several exact-size targets. The FAQ also describes adjustable quality settings. Those statements should not be combined into an unconditional promise that every image can meet every byte target without perceptible change. This review has not measured compression ratios or inspected artifacts, so it does not verify claims about preserving quality across every source and target combination.

The useful result is a file that satisfies both the technical constraint and the visual requirement, with the trade-off understood rather than hidden behind an exact-size label or a broad quality claim.
