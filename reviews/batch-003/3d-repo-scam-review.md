# 3D Repo review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-17  
**Category:** Cloud BIM coordination and construction collaboration software  
**Method:** Source-led desk review; no hands-on testing is claimed.

3D Repo is a browser-based platform for coordinating building-information models and construction project data. Its public materials describe federated model collaboration, issue tracking, data validation, model checking, 3D change detection, APIs and integrations with common authoring and analytics tools. Pricing is quote-based and tiered by team or project needs. Buyers should test actual model sizes, version comparisons, permissions, data residency and export before placing live project information into the service.

## Editorial verdict

The vendor publishes identifiable features, quote-based licensing information, hosting options, a privacy notice and technical documentation. It also describes UK, Canada, private-cloud and on-premises deployment options. Nothing in the evidence reviewed supports a scam allegation. The material issue is procurement clarity: several pages are dated, pricing requires a quote, and the privacy notice is old. Request current contractual terms, a current security pack, a model-sized pilot and a written data-export plan before relying on it for a construction project.

## What 3D Repo is for

3D Repo is a building-information-model collaboration platform for construction teams that need to review coordinated models and project information in a shared environment. The vendor describes access through a web browser, with project models uploaded and grouped so architects, engineers, contractors and owners can work from a common project view. Its intended value is keeping model coordination and issue follow-up connected, rather than exchanging disconnected screenshots and marked-up files.

The platform is positioned for multi-party construction work where different disciplines contribute their own model revisions. A model viewer alone does not solve coordination: the team also needs clear version control, issue ownership, permission boundaries and an agreed process for deciding which model revision is authoritative. Those operational rules matter at least as much as the rendered 3D scene.


## Model coordination, issues and change detection

The feature pages list 3D issue pins, issue tracking, APIs, plugins, model checking, data validation and 3D Diff change detection. The vendor says 3D Diff can highlight differences between model revisions even when object identifiers or underlying file structures differ. If it works well on a project’s authoring outputs, change visualization may help reviewers focus on the relevant parts of a large model instead of manually comparing entire files.

That is a vendor-described capability, not a result independently reproduced for this review. Test it on the same formats and model revisions the project actually uses, including geometry changes, metadata changes, deleted elements, coordinate shifts and revisions produced by different authoring tools. Ask how false positives are represented, whether reviewers can filter by discipline or object type, and how a detected change becomes a tracked decision. A comparison view does not itself certify that a design is correct or safe.


## Plans, licensing and deployment options

The pricing page offers small-team, project-team and enterprise arrangements and directs prospective customers to request a quote. It describes licensing in terms of users, storage and processing, projects, APIs, support and features such as issue tracking, model checking, 4D and data validation; some values are shown as unlimited subject to fair use. The page does not provide a universal fixed monthly price, so a buyer should not budget from a generic “unlimited” label.

The hosting page describes instant SaaS access, private-cloud deployment and on-premises options. It says managed deployments use Microsoft Azure and describes UK regional storage, while other hosting arrangements can be discussed. Confirm the exact option offered, cloud provider and region in the order form; also clarify who patches the application, manages backups, monitors availability and restores a project after an incident. Hosting, support and SLA terms should be written into the agreement rather than inferred from a marketing page.


## Data rights, privacy and documentation age

3D Repo’s pricing page says the company opposes vendor lock-in and describes users working with their data. That is a useful principle, but a procurement decision needs operational detail: export formats, model history, annotations, issue records, attachments, permission metadata and the effort required to move a project elsewhere. Test an export early, not only when a project is ending.

The privacy notice explains personal information and collaboration data and identifies 3D Repo Limited, but the page states that it was last updated in 2021. The hosting page is more recent and discusses deployment locations and cloud infrastructure. For a current project, request the present data-processing terms, subprocessors, incident-notification obligations, retention schedule, deletion procedure and current independent security reports. The age of the public notice is a documentation gap to clarify; it is not proof of a security incident or bad faith.


## Implementation and project risks to test

A pilot should use a representative model federation rather than a small demonstration file. Measure upload and processing time, viewer performance, collaboration latency, issue search, model revision handling and export. Include a difficult coordination example with a known clash or missing attribute and verify that the platform lets the right person identify, assign, resolve and audit it.

Confirm authoring-software versions, supported file formats, coordinate reference handling, model-size limits, retention and access for external contractors. Decide whether project collaborators need paid seats, guest access or temporary roles; the pricing page presents access tiers that should be mapped to the actual team. If offline site work is important, verify that exact workflow separately rather than assuming a browser-based platform is fully available without connectivity.


## Alternatives and a meaningful evaluation

Compare 3D Repo with the collaboration and model-coordination tools already used by the project, including authoring-suite collaboration features, common data environments and specialist issue-management systems. Use the same model files and acceptance criteria. Compare format coverage, version clarity, clash or change workflows, field accessibility, audit trails, APIs, hosting, exit rights and total project cost.

A useful quote should break out licenses, storage or processing, support, SLA, hosting, onboarding, integrations and any optional plugins. Ask whether project teams can export data without additional professional services and whether the customer can self-host or inspect the specific code being offered. No 3D Repo tenant, construction model, performance run or security configuration was tested for this review.


## Is 3D Repo a scam? Review conclusion

3D Repo has a public product feature set, a licensing page, hosting descriptions, a user manual and a privacy notice. Its published offer is consistent with BIM collaboration software, and nothing reviewed supports labelling the company a scam. The product may suit project teams that need browser-based model review, issue coordination and change visibility.

The buyer should treat quote-based pricing, fair-use limits, old privacy wording and model portability as diligence items. Secure a current contract and security pack, test the project’s real file set and validate an export before committing high-value project records. This review uses vendor-published information and historical context from Wikipedia; it is not a live product test, customer reference check or assurance audit.


## Features and decision criteria

- Cloud BIM model coordination and federated project models
- 3D issue pins, assignments, model checking and data validation
- 3D Diff change detection across model revisions and formats
- Quote-based small-team, project-team and enterprise licensing with hosting options
