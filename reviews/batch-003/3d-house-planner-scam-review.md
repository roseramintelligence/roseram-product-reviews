# 3D House Planner review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-17  
**Category:** Browser-based 2D, 3D and BIM home-design software  
**Method:** Source-led desk review; no hands-on testing is claimed.

3D House Planner is a browser-based design application for drawing floor plans, building editable 3D homes and exporting models to BIM and CAD formats. The current homepage says it is free, needs no login, stores projects in the user’s browser and does not upload design data; it also advertises an AI assistant and IFC4, DXF, GLB and other exports. Its older privacy and terms pages contain broad, generic language about advertising cookies and a license to displayed user content, so users handling private plans should clarify which current terms govern the application and AI features.

## Editorial verdict

The live product page describes a useful, free design tool and specific local-storage and export behavior. The evidence reviewed does not support calling the application a scam. The notable issue is a mismatch between the modern product promises and older legal pages: the privacy notice describes advertising and third-party cookies, while the terms use a broad content-license clause. Before uploading plans, photos or client work to any AI feature, confirm whether those files remain local or are sent to an AI provider and how the applicable terms treat them. Back up browser-stored projects by exporting them.

## What the current 3D House Planner offers

3D House Planner is a web application for designing houses and apartments. The current product page describes a workflow that starts with drawing a plan, describing a design to an AI assistant or importing a file, then editing the result in synchronized 2D and 3D views. It says walls, floors, doors, windows, roofs and furniture remain editable after AI assistance. The site also presents BIM-oriented information such as IFC classes and properties, quantities and model checks.

The public page says the app is free for personal and commercial use, requires no login and has no watermark. It lists import and export for IFC, DXF, GLB/glTF, OBJ, STL, SVG, PNG, CSV and JSON-related formats, and advertises 50 floors per project and several visualization modes. This is an unusually generous offer for a browser-based floor planner, but buyers should still confirm which AI actions call external services and whether there are any separate provider limits.


## Design workflow, AI and export options

The AI assistant is described as generating editable building elements from a text prompt or attached plan, photo or model. The product presents a live relationship between the 2D plan and 3D scene, plus rendering modes from a lightweight draft to higher-quality reflections and ambient occlusion. For an early concept or interior layout, this lets a user move from a rough plan to a navigable model without first installing a large desktop CAD package.

The export list is useful for moving work into other applications, but import and export fidelity should be tested before relying on the project for construction documents. Check units, scale, coordinates, IFC classifications, object properties, dimensions, texture links and round-trip behavior in the target CAD or BIM system. A visually convincing model is not a stamped architectural plan, code review or engineering validation. The app’s output should be treated as a design aid unless a qualified professional verifies it for the intended purpose.


## Privacy claims and browser-based project storage

The current homepage says projects are saved in the user’s browser using local storage with autosave and crash recovery; it says no account, upload or database is involved for those projects and that users can export everything. The page also states that design data is not collected and offers import and export so work can be moved to another device. This can be attractive for privacy-conscious users because the main project file is not described as living in a vendor cloud account.

Browser storage is device- and browser-specific. Clearing site data, changing profiles, using private browsing or moving to a new computer may remove access unless a project has been exported. Users should download regular backups and test restoring one. More importantly, the AI feature can behave differently from the local editor: the homepage invites users to attach a plan, photo or model. Before submitting confidential designs, ask where those attachments are processed, whether an external AI service receives them, what retention applies and whether the user can disable that functionality.


## Older privacy and terms pages need clarification

The published privacy page contains language about Google DoubleClick advertising cookies, third-party ad servers and visitor logs. The terms page includes restrictions on website use and a broad license for “Your Content” that is displayed on the site. These pages appear more generic and older than the current product description, which emphasizes no login and local project storage. The available public material does not make clear how those older provisions apply to local design files, shared views, AI attachments or other current features.

This is a documentation mismatch to resolve, not proof that designs are being collected or misused. Ask the developer for the current privacy notice and terms that govern the app, a clear explanation of any analytics and advertising cookies, and a direct statement about AI processing and training. If a client contract or confidential project is involved, avoid uploading source material until the data flow and content license are clear. The related 3D Sales Table is a separate tool and publishes its own description; do not assume its data handling is identical to the planner.


## Pricing, account model and practical limitations

The current product page says the app is free, including commercial use, and accepts donations. It says there is no account requirement or install step. That keeps the initial cost low, but a no-account product may not provide the recovery and team administration expected from a hosted SaaS. The user is responsible for browser backups and should determine whether there is a support or service-level commitment before using it in a paid design workflow.

Check which device and browser capabilities are needed for the highest visualization settings. The page says users can choose draft, balanced, high, ultra and AI-photo modes, and notes that more demanding effects depend on the computer’s GPU. Test on the machine and browser that will be used in practice. A low-powered laptop may still handle basic layouts but not deliver the same rendering experience as a workstation.


## Alternatives and a sensible evaluation

Compare the tool with other browser floor planners, desktop home-design applications and full BIM systems. A free browser tool may be excellent for planning rooms, communicating an idea or preparing a model for a professional. A production architecture practice may need multi-user project controls, audit history, cloud recovery, detailed documentation, code compliance checks and contractual support that a free personal tool may not promise.

A useful test is to create a small plan, close and reopen the browser, export the project, import it on another device, and open the resulting files in the destination tool. Check dimensions, wall openings, levels, properties and textures. Try one AI-assisted change and inspect whether it preserved the geometry and constraints you care about. No project, AI operation, export or browser recovery was independently tested for this review.


## Is 3D House Planner a scam? Review conclusion

The current site describes a functioning design application with a broad set of features, import/export formats and a local browser storage model, and it makes a clear free-to-use claim. The available evidence does not support calling the product a scam. The main diligence issue is that older privacy and terms pages do not clearly align with today’s product description, especially around advertising language and the license for displayed content.

Back up work outside the browser, clarify the handling of AI attachments and obtain current terms before using private client plans. Treat visual outputs as design materials that still need professional review for construction or regulatory use. This review is based on public product pages and documentation; no live account or model was tested, and the privacy mismatch should be resolved directly with the publisher.


## Features and decision criteria

- Live synchronized 2D floor plans and editable 3D house models
- AI design assistant for layout and object creation
- IFC4, DXF, GLB/glTF, OBJ, STL, SVG, PNG and CSV import/export options
- Projects stored in browser storage according to the current product page
