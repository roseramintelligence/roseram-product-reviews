# Odoo review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-24  
**Category:** Business management and ERP software  
**Method:** Source-led desk review; no hands-on testing is claimed.

Odoo is a suite of connected business apps spanning CRM, accounting, inventory, eCommerce, website, HR, project management and more. Its hosted plans are priced per user, with a One App Free option and different hosting and customization choices on the Custom plan.

## Editorial verdict

Odoo is appealing to businesses that want sales, operations and back-office tools connected in one system and are prepared to scope an implementation. The one-app free plan lowers the cost of a narrow trial, but expanding into a broader suite changes the pricing and setup equation. Compare the required apps, active users, custom code, hosting and implementation services before selecting a plan.

## Start with one workflow before adopting the suite

Odoo can connect customer management with accounting, inventory, websites and other operational apps. That breadth can reduce duplicate data and handoffs, but it also makes scope important. A company that needs only a sales pipeline may not benefit from configuring manufacturing or finance modules at the same time.

Choose one end-to-end process such as lead-to-quote or order-to-invoice. Identify the records, approvals and reports needed at each step, then test that flow using sample data. Add apps only when a real workflow depends on them, and name an owner for each module so the system does not accumulate unused configuration.


## Understand the One App Free boundary

Odoo’s pricing page lists a One App Free plan with unlimited users for one selected app. Some required dependency apps may be included when a chosen app depends on them. The company’s plan conditions say that installing additional applications can switch the database to a paid tier, so the free label should not be read as a full-suite promise.

During evaluation, list every module that is enabled and ask an administrator to confirm the resulting plan before installing a new app. Check whether the chosen app’s dependencies cover the intended workflow and what happens when the organization adds a company, customizes code or needs external API access.


## Compare hosting and customization options

The Standard plan is presented as hosted Odoo Online without custom modules. The Custom plan adds choices that include Odoo Online, Odoo.sh or on-premise deployment, with Studio, multi-company and external API capabilities. The official pricing page says Odoo.sh hosting for custom developments is not included in the plan amount.

Make a deployment decision based on the integrations and customizations the business genuinely needs. Include hosting, backups, upgrades, custom code maintenance and technical staff time. For an on-premise setup, confirm who patches the server and tests upgrades. For hosted use, check backup exports and data portability.


## Budget users and implementation, not just subscription

Odoo lists per-user pricing and defines which backend roles count as paying users; some employee records can also affect the count. The pricing page separately excludes implementation services, expert access, maintenance of custom code and certain in-app purchases. A subscription quote alone may not capture the project cost.

Request a written proposal that separates licenses, implementation, migration, training, custom development and ongoing support. Model the planned user count at launch and after growth. Have finance and operations validate the plan assumptions before committing. This review summarizes official information and is not an implementation estimate or accounting recommendation.


## Features and decision criteria

- Connected CRM, accounting, inventory, website and operations apps
- One App Free with unlimited users for one selected app
- Standard hosted plan and Custom deployment options
- Custom API access, multi-company and code customization depend on plan

## Pricing considerations

The official page excludes Odoo.sh hosting for custom development, implementation services, custom-code maintenance and certain in-app purchase credits. Prices and promotions can vary; confirm current billing, user definitions, hosting and country-specific terms before purchase.

## Frequently asked questions

### Does One App Free mean the whole Odoo suite is free?

No. The official plan describes one selected app; dependent apps may be included, but adding more applications can move the database to a paid plan.

### Does Odoo Custom include Odoo.sh hosting?

The plan lists Odoo.sh as a hosting choice, but the official page says Odoo.sh hosting cost is not included.

### Are all staff members billable users?

Odoo defines paying-user treatment by backend access and certain employee records; confirm the current user definition for the organization.
