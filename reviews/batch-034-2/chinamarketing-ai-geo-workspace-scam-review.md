## Chinese Generative Engine Support and Retrieval Execution Mechanics

A primary requirement for evaluating any regional visibility software is the breadth and technical execution of its supported language models. The published documentation for GEO Workspace states that it provides query access across six distinct Chinese AI engines: DeepSeek, Doubao, Yuanbao, Qwen, ERNIE, and Kimi. These models stem from major domestic technology corporations and independent research teams within Mainland China. By executing an identical question set across these distinct engines, the system is designed to reveal where outputs show consensus, where they diverge, and how individual platforms source their recommendations.

The software executes queries through two distinct operational paths: Model Only and Search Enhanced. In Model Only mode, the platform queries the base language model directly, relying entirely on the weights established during training without connecting to live web search. This mode reflects what an engine generates from its historical training data alone. In Search Enhanced mode, the query is routed through available provider search or retrieval mechanics, pulling live web links and current citations into the final answer. When an engine does not support live search integration, the platform displays the actual condition under which the query was completed.

Differentiating between base model generation and retrieval-augmented output is vital for diagnosing visibility issues. If a brand appears prominently in Search Enhanced mode but is completely absent from Model Only answers, the organization likely has active web indexing but weak historical representation in the model's core training corpus. Prospective buyers must verify how reliably each provider's retrieval pipeline functions in live production. Domestic Chinese model APIs frequently modify their search connectors, making hands-on verification during initial software onboarding a necessary step for technical teams.


## Baseline Report Locking and Longitudinal Monitoring Controls

A chronic flaw in tracking generative outputs is that continuous model updates and shifting prompt structures make longitudinal comparisons unreliable. ChinaMarketing.AI attempts to mitigate this by implementing immutable baseline reports. Once an initial assessment—typically configured around a standard 20-question plan—is completed, the team can publish and lock the report. This action freezes the approved questions, competitor parameters, and engine choices into a permanent historical benchmark. Future monitoring rounds are evaluated directly against this frozen dataset to measure changes over time.

The tracking system operates using configurable review reminders set on weekly, monthly, or quarterly schedules. Notably, the software separates automated calendar alerts from billable query execution. When a scheduled review date arrives, the system sends a notification to designated account owners or administrators, but it does not execute background API calls automatically. An administrator must log in, review the projected credit cost for the run, and explicitly approve execution. This approval gate prevents unexpected credit consumption and ensures human oversight over when historical baselines are refreshed.

When an approved tracking run finishes, the platform matches newly captured responses against historical baseline answers. The system highlights stable answers where messaging remained consistent, flags material changes where models cited new competitors or altered recommendations, and notes coverage gaps where an engine failed to complete a call. However, enterprise buyers must recognize that baseline comparisons do not measure consumer market share or sentiment at scale. The software only documents how fixed prompt sets perform within configured parameters across specific dates.


## Credit Metering Mechanics, Provider Failures, and Rollover Rules

ChinaMarketing.AI meters platform consumption using an internal billing unit termed GEO Credits rather than passing raw vendor API token fees directly to the client. Under this credit accounting framework, one completed question and engine response in Model Only mode consumes exactly one GEO Credit. For instance, running a 20-question audit across five configured engines in Model Only mode requires 100 credits. If the user executes the same 20 questions across five engines in Search Enhanced mode, the rate rises to 1.5 credits per successful response, totaling up to 150 credits, provided all selected engines support search retrieval.

The platform includes specific rules governing technical provider errors and unused balances. If a Chinese model provider encounters an API outage, timeout, or technical execution failure, the platform bills zero credits for that failed query attempt. Furthermore, unused monthly subscription credits roll over into subsequent billing periods, up to a maximum cap equal to three times the subscriber's monthly plan allotment. This rollover policy provides flexibility for corporate teams that conduct irregular, quarterly brand audits rather than running continuous weekly evaluations.

Corporate procurement teams should calculate their estimated assessment volume carefully before committing to a monthly tier. Running a complete 20-question plan across all six supported engines in Model Only mode burns 120 credits per run. If analysts routinely use Search Enhanced execution or deploy supplementary Advanced Analysis modules, credit burn increases noticeably. Teams managing several product lines or monitoring multiple competitor sets could easily exceed baseline monthly quotas without disciplined usage planning.


## Subscription Tier Structure, Project Quotas, and User Access

The platform structures its self-service software into three public monthly subscription tiers alongside bespoke enterprise packages. The Core plan costs $299 per month and provides 700 GEO Credits, which the publisher estimates covers approximately five standard assessments. This entry tier restricts workspace capacity to a single active project and two user logins, making it suitable primarily for a single brand, regional venue, or product entity. Subscribers paying annually receive an effective discount equivalent to two free months, though credit balances continue to replenish on a monthly schedule.

The Pro plan costs $699 per month and provides 2,000 GEO Credits, supporting an estimated 16 standard assessments per monthly cycle. This tier expands workspace limits to three active projects and five user seats, suiting marketing agencies or regional corporate divisions tracking multiple operating entities or territories. For larger teams, the Business tier costs $1,499 per month and supplies 5,000 GEO Credits, 10 active projects, and 15 user seats. Custom Enterprise contracts are available for organizations requiring customized credit scale, bespoke security configurations, or specialized data governance controls.

Buyers should evaluate these seat and project constraints against their internal team structure. ## Frequently asked questions

It is a self-service software dashboard that runs structured Simplified-Chinese questions across selected Chinese generative AI engines. ### How does the platform meter and bill for individual query executions?

Usage is calculated via GEO Credits instead of raw token counts. A completed response in Model Only mode consumes one credit, while a Search Enhanced response consumes 1.5 credits. Provider connection failures are not billed, and unused monthly subscription credits roll over up to three times the monthly plan cap.

### Does the system automatically run recurring monitoring audits in the background?

No. The system issues automated weekly, monthly, or quarterly review notifications, but it does not execute background model calls autonomously. An account owner or administrator must review the estimated credit quote and explicitly approve execution before a follow-up run begins.

### Does ChinaMarketing.AI guarantee improved search rankings or AI brand endorsements?
