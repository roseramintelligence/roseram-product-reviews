# WordPress review: features, pricing and buyer considerations

**Last editorial review:** 2026-11-16  
**Category:** Website publishing and content management  
**Method:** Source-led desk review; no hands-on testing is claimed.

WordPress is a publishing system. The WordPress.org export tool creates a structured content file that can be imported elsewhere.

## Editorial verdict

WordPress.org documents the publishing project and its built-in export. Hosting providers, theme stores and maintenance contractors make their own commercial offers.

## WordPress WXR export before a new host takes over

The new host should know exactly what readers expect to find. Create a **WordPress WXR export** and import it into a staging site. Compare a post with an image, a page with a custom field and a discussion with comments. Follow links from the old site to decide which paths need redirects.

Treat the export as a content transfer. Plan separately for themes, plug-in settings, uploaded files and everything else required to reproduce the whole installation. Ask the new host for a written description of what its migration includes.


## WordPress hosting and maintenance costs for a small team

Start with the job the site must do, such as collecting a lead or selling a product. List which extensions are essential and who can repair each one if an update changes its behavior. Restore a copy and rehearse a rollback before the first high-traffic campaign.

The *total cost to keep publishing* includes ownership of updates, security maintenance and help during failures. Put those responsibilities side by side when comparing a managed provider with a server your team runs.


## Features and decision criteria

- Content publishing and organization
- WXR content export
- Themes and plug-in-based site workflows
